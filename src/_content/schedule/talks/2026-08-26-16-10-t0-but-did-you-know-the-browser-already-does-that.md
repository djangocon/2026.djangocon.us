New features in HTML and CSS mean a better dev experience for providing better user experiences. But are they too new to use? In this talk, you'll get a glimpse at some of the newer features of the web platform. Once you're excited to use them in your project, we'll take a look at browser support, and how to use Baseline to evaluate whether it's ready to use in your project.

We will cover:

- Popovers: native tooltips
- Anchor positioning: placing tooltips and dropdowns
- Invokers: interactivity without needing JavaScript
- Container queries: styles based on context, not the screen
- View transitions: Animating between pages
- Custom selects: Native select options that match your UI

And more!

But how do you know if a feature has enough support? You will also learn how easy it is to evaluate support with Baseline, which is integrated into IDEs, linters, and throughout the web.
