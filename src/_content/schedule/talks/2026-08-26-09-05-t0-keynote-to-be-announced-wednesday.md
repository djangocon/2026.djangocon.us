Django 6.0 has multiple very exciting new features, including:
- Template Partials
- Background Tasks Framework
- Content Security Policy
- Modern Email API

In this talk we'll discuss each of these features, illustrating why you may want to start using them as soon as possible. Additionally we'll cover some tips and tools for a smooth upgrade experience. By the end of the talk we believe you'll agree that Django 6.0 has earned the accolade of most exciting Django release ever.
